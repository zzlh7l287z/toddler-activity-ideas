# 【儿科科普】儿童雾化吸入治疗的作用和注意事项

> 更新时间：2026-09-16 (UTC+8)

随着医疗技术的不断发展，近年来，雾化吸入治疗以其起效快、用量小、不良反应少等优点，被广泛应用于临床，用于治疗毛细支气管炎、哮喘性支气管炎、支气管哮喘、急、慢性支气管炎、急性喉炎、急性肺炎等儿童呼吸系统疾病。

目的
应用雾化装置将药液分散成细小的雾滴或微粒，经鼻或口吸入呼吸道及肺内充分发挥作用，药物直达病灶，帮助呼吸道疾病更快治愈。

作用
1. 湿化气道 对痰液粘稠、气道不畅的患儿起到气道湿化的作用；

2. 控制感染 消除炎症，帮助控制呼吸道感染。常用于咽喉炎、支气管扩张、肺炎、肺脓肿的病人。

3. 改善通气 解除呼吸道痉挛，保持气道通畅。常用于支气管哮喘的病人。

4. 祛痰镇咳 减轻呼吸道黏膜水肿，减轻气道高反应，稀释痰液。

注意事项

1. 雾化吸入前后20分钟禁食水，防止雾化吸入中气雾刺激呼吸道，引起呕吐、呛咳造成误吸。

2. 雾化时尽量用口呼吸、鼻出气，以促进药物的充分吸收到达肺部。

3. 雾化时尽量采取半卧位或坐位，有利于胸廓幅度的增大、促进药物吸收。

4. 如用氧气的患儿雾化结束后，及时关掉氧气，避免吸入氧气过多。

5. 雾化后用温开水漱口，小宝宝用毛巾擦洗面部。

6. 雾化后要帮助患儿拍背，促进痰液的排出。

7. 雾化结束后，对雾化杯进行清洗、晾干，以备下次使用。
