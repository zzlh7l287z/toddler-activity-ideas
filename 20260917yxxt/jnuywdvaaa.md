# 齐鲁医院生殖医学中心文献速递第21期—Epg5缺乏导致小鼠颗粒细胞中WT1积累进而引发早发性卵巢功能不全

> 更新时间：2026-09-17 (UTC+8)

**01**

**研究背景**

早发性卵巢功能不全(POI)是一种以40岁前提前绝经为特征的疾病，伴有促卵泡激素升高。POI是一种高度异质性的疾病，由遗传或其他未知因素引起的孤立或综合征形式，然而，在大多数病例中，POI的发病机制仍未明确。减数分裂和DNA修复基因的突变是导致卵母细胞综合征和非综合征性POI的原因，有报道称POI与STAG3、SMC1B、REC8、SYCE1、MCM8、MCM9、DMC1、HFM1和XRCC4的突变有关。颗粒细胞(GCs)是卵泡体细胞，提供必需的营养和生长因子，它们也分泌卵泡形成过程所需的类固醇。GC功能障碍可引发卵泡闭锁和细胞凋亡，最终导致POI。
自噬是细胞胞质成分和受损细胞器降解和再循环的主要生物过程，从酵母到哺乳动物在进化上都是保守的。巨噬/自噬的溶酶体降解途径在细胞生理学中发挥重要作用。在这一途径中，自噬体与溶酶体融合，形成自噬体，然后自噬体降解封闭的物质。自噬经过几个严格调控的步骤，从吞噬体的形成到自噬体，自噬体与溶酶体融合形成最终的降解结构，从而为细胞在应激条件下的生存提供原料。EPG5(异位p-颗粒自噬蛋白5同源物是一种RAB7A效应物，可介导自噬体与晚期内体或溶酶体之间特异性融合。通过USP8(泛素特异性肽酶8)去泛素化EPG5调节小鼠胚胎干细胞的自噬通量以维持其干性。先前对哺乳动物生殖的研究表明，自噬对于精子发生和卵泡发生都是必不可少的;然而，常规敲除大多数自噬相关基因会导致产后快速死亡，因此，自噬在男性和女性不育中的功能作用的几个方面仍不清楚。在本研究中，研究者发现敲除Epg5阻断自噬通量，导致雌性小鼠出现POI样表型。在Epg5基因敲除小鼠中，转录因子(WT1)的蛋白水平显著升高，这反过来又降低了窦卵泡GCs中类固醇基因的表达。因此，此研究揭示了EPG5通过促进WT1降解在调节卵泡发育中的重要作用，这表明人类EPG5突变可能与POI有关。

**02**

**研究摘要**

POI女性在40岁之前出现性腺功能减退。目前，POI的发病机制在很大程度上仍然是未知的。研究人员发现敲除Epg5导致雌性小鼠表现出POI样表型的低生育能力。单细胞RNA测序分析显示，敲除Epg5影响颗粒细胞(GCs)的分化。进一步研究表明，敲除Epg5阻断自噬，导致转录因子WT1在Epg5 GCs中积累，表明WT1需要通过自噬途径选择性降解。研究发现WT1的降解不足导致甾体生成相关基因的表达减少，从而破坏了GC分化。EPG5促进了GCs中WT1的降解，这表明EPG5在GCs中的失调可以触发POI的发病机制。

03

**研究结果**

**1.Epg5基因缺失导致小鼠卵泡发育功能障碍和生育能力低下。**

与许多其他自噬相关基因不同，最近发现的自噬相关基因Epg5的敲除不会导致小鼠出生死亡 ，从而可以研究其在生育力中的作用。我们最初检查了不同小鼠组织中的Epg5表达，发现其在卵巢中显著表达。在蛋白质水平上，Epg5在GC中同样高表达。卵巢免疫组织化学染色显示原始卵泡、初级卵泡、次级卵泡和窦卵泡的GC中有强烈的Epg5信号。这些结果表明Epg5可能参与GC的某些功能。

Epg5敲除小鼠的卵巢形态显示，卵巢明显减小，卵巢重量/体重比也显着下降。为了研究Epg5敲除对雌性生育力的影响，随后进行了生育力检测，与对照雌性相比，Epg5敲除雌性的生育能力降低，每窝幼崽的数量更少。H&E染色发现Epg5敲除卵巢中卵泡发育异常。研究者比较了不同年龄的卵巢形态，发现Epg5敲除和3周龄对照卵巢之间没有明显的形态差异：卵巢具有相似数量的各种阶段卵泡。然而，检测6周大的小鼠发现Epg5敲除卵巢中的原始卵泡、初级卵泡和窦卵泡的数量显著减少。这些结果表明，Epg5缺失可能会导致女性卵泡发育功能障碍和生育力低下。

**2.敲除Epg5不影响小鼠卵母细胞的发育能力**

雌性的生殖能力是基于卵母细胞和卵泡的发育调节而维持的。为探讨Epg5是否影响卵母细胞功能。实验发现Epg5敲除小鼠中排卵的MII卵母细胞数量减少。为了评估Epg5缺失卵母细胞的发育潜力，从小鼠中分离出生发囊泡 (GV) 卵母细胞体外培养。发现Epg5敲除卵母细胞的MII率与对照卵母细胞没有差异。为了进一步研究 Epg5敲除小鼠卵母细胞的发育潜力，将卵母细胞进行IVF。发现Epg5敲除小鼠2细胞胚胎和囊胚形成率没有显着差异。这些结果表明，Epg5敲除雌性的生育力低下是由于卵泡发育和排卵缺陷而不是卵母细胞发育改变所致。

**3.敲除Epg5导致GCs老化和细胞死亡**

GC为卵母细胞提供必需的营养物质和类固醇，在卵泡发育中发挥重要作用。研究者评估了GC功能失调是否可能是Epg5敲除小鼠POI样表型的原因，于是研究者检测了衰老相关的GLB1/β-半乳糖苷酶，发现Epg5敲除GLB1/β-半乳糖苷酶活性显著增加。TUNEL染色发现Epg5敲除小鼠卵巢GC凋亡水平显著增加。Epg5敲除导致GC DNA损伤增加。

**4.在敲除Epg5的GC中，自噬通路被阻断**

之前研究发现EPG5通过与RAB7直接相互作用并与晚溶酶体上的VAMP7-V AMP8复合物结合而被招募至自噬体。接下来研究者检查了Epg5是否影响小鼠卵巢的自噬活性。Epg5敲除 GC显示自噬标记物 MAP1LC3/LC3水平显着增加，表明自噬流被阻断。Epg5敲除GC中的LC3和SQSTM1水平同样显著升高。通过延时显微镜监测了Epg5敲除GC中的自噬流，发现自噬体与对照GC中的溶酶体融合，而LC3在Epg5敲除GC中急剧积累。这些结果证实,Epg5敲除的GC中自噬流被阻断。

**5.单细胞RNA测序分析显示Epg5敲除GCs分化异常**

为了研究 Epg5在卵泡发生过程中的调节机制，对6周龄Epg5敲除小鼠和对照小鼠整个卵巢的分离细胞进行了单细胞RNA测序，结果发现卵巢中GC的比例下降。Epg5敲除小鼠的GC中有25个差异表达基因编码性激素生物合成酶的Cyp11a1和Cyp19a1。GO分析表明，基因富集了与“转录的正调控”、“转录因子结合细胞”、“对激素刺激的反应”、“雌激素信号通路”、“细胞凋亡的正调控”相关的功能相关，还鉴定了20个包含868个基因的重要调节子。调节网络中的关键调节子表明调节子的高表达，包括 Bclaf1、Atf4、Fos、Wt1、Jun 和 Foxo1 调节子，所有这些调节子都是维持 GC 分化和卵泡闭锁过程的明确调节因子。Western blot结果显示，与对照组相比，BCLAF1、ATF4、FOS、JUN/c-JUN和FOXO1的蛋白水平没有变化。在富集的调节子中，WT1 的蛋白水平在Epg5敲除卵巢中显着增加。scRNA-seq 分析表明，Epg5的敲除显着扰乱了GC分化基因的表达。

**6.Epg5通过降解WT1调控GCs的分化**

众所周知，WT1 作为多种类固醇生成基因的转录抑制因子，在卵泡发生过程中抑制GC的分化。为了研究自噬缺陷如何影响GC分化，研究者通过免疫荧光进一步检测了WT1蛋白水平，发现Epg5敲除GC中WT1有明显的积累。推测，Epg5敲除 GC 中观察到的WT1积累可能是由于WT1蛋白的降解破坏造成的。马绒毛膜促性腺激素 (eCG)/孕马血清促性腺激素 (PMSG) 促排卵，处理后Epg5敲除卵巢中观察到 WT1蛋白的积累。此外，观察到Epg5敲除小鼠的窦卵泡中 WT1 没有降解。这些结果表明，Epg5敲除小鼠的初级和次级卵泡具有正常的WT1积累，但WT1 降解受损导致窦状卵泡和排卵前卵泡中异常高的WT1积累。

综上所述，Epg5敲除GC中自噬流受阻，窦卵泡和排卵前卵泡中WT1 蛋白降解破坏，接下来研究者在293T细胞的一系列体外实验中探索了潜在的WT1受阻自噬关系。将自噬/溶酶体抑制剂 3-甲基腺嘌呤 (3-MA) 添加到转染 Wt1表达质粒的293T细胞中。在放线菌酮 (CHX) 追踪实验中，WT1降解在3-MA处理后明显延迟。此外，293T 细胞中的免疫共沉淀实验表明，WT1 可以与SQSTM1发生物理相互作用，但不能与NBR1、LC3和TOLLIP发生相互作用。在Epg5敲除的GC中，SQSTM1 并未与WT1共定位，表明Epg5敲除的GC中WT1降解存在缺陷。总的来说，这些结果表明 WT1通过自噬-溶酶体途径降解。

**7.在Epg5敲除的GCs中，类固醇基因的表达可以通过敲低Wt1来部分恢复**

     已有研究证明WT1功能的丧失会导致前颗粒细胞转化为类固醇生成细胞，Epg5敲除GC中已知的类固醇生成蛋白的水平。包括 FSHR（卵泡刺激激素受体）、HSD3B1/3β-羟基类固醇脱氢酶（羟基-δ-5-类固醇脱氢酶、3β-和类固醇 δ-异构酶 1）、Cyp11a1。此外，Chen等人证明，WT1通过直接结合到Sf1启动子区域来抑制Sf1表达，并表明Wt1失活会导致Sf1上调，进而激活类固醇生成程序。本实验结果发现eCG/PMSG处理的3 周龄Epg5敲除卵巢中FSHR、HSD3B1、CYP11A1 和 CYP19A1 水平降低。为了探讨自噬对GC分化的影响，从Epg5敲除小鼠中分离并培养了5至6周龄小鼠的 GC。氯喹 (CQ) 用于抑制 GC 中的自噬。CQ 处理后GC的LC3-II和WT1水平显着增加，与Epg5敲除的GC类似。此外，Epg5敲除和CQ处理的GC中GC分化相关蛋白的水平明显下降。这些结果表明，阻断自噬显着影响 GC 分化。为了测试EPG5敲除GC中类固醇生成基因ACCEPTED，MANUSCRIPT15的下调是否是由于WT1积累所致，使用siRNA下调EPG5 GC中WT1的表达。发现WT1的敲低部分挽救了GC分化相关基因的表达，表明WT1是GC分化中的主要自噬靶标。

       结果支持EPG5敲除GC 中自噬的阻断导致 WT1 的异常积累，导致 GC 分化相关蛋白的水平异常低。
